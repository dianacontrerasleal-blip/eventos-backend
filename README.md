# Sistema de Gestión de Eventos (Backend)

Este es el proyecto base para la gestión de eventos y boletos.

## Tecnologías
- Python 3.11
- FastAPI
- PostgreSQL
- SQLAlchemy & Alembic
- Docker

## Cómo levantar el entorno local

1. Clonar el repositorio.
2. Ejecutar Docker Compose:
   ```bash
   docker compose up -d
   ```
3. Visitar `http://localhost:8002/docs` para ver el Swagger de la API.
